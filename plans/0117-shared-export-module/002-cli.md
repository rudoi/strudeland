# 002: the CLI on the export module

## Goal

`strudeland render` runs through `strudeland_render::export`. Its stdout, stderr, flags and exit
codes stay byte-identical. `RenderBackend`, `StrudelandBackend`, `Plan`, the CLI's `Destination`,
`ExportPlan` and `ExportPlan::write` are deleted. Every CLI render test moves onto
`strudeland_render::testing::FakePipeline` with its assertions unchanged.

## Prerequisites

- **Stage 001 is committed.**
- **Read `crates/strudeland-cli/src/render.rs` and `run.rs` `run_render`** (:479-525), and the
  proposal's Entry points, Progress and Wording sections.

## Implementation

### `crates/strudeland-cli/src/render.rs`

1. **Delete** `RenderBackend`, `StrudelandBackend`, `Plan`, `Destination`, `ExportPlan`, `plan()`
   and `ExportPlan::write`. Update the module doc comment ("option resolution, the export adapter,
   progress and the summary output").
2. **Imports:** `use strudeland_render::export::{self, Destination, Event, Finished, Kind,
   Prepared, Request, RunError};`, plus what the kept code still uses.
3. **`stem_options(args) -> Result<(), RenderError>`:** the same conflicts array in the same
   order, then `EncoderOptions::from_flags(Format::Wav, Some(BitDepth::F32), args.mp3_mode,
   args.quality)?` for its errors only. The result is dropped, because the module fixes the stem
   output.
4. **Add `prepare`:**

   ```rust
   /// Resolves the flags and the destination before any work, so a bad flag or a missing
   /// `--out` fails fast. Creates nothing and never stats an explicit `--out`.
   pub fn prepare(args: &RenderArgs) -> Result<Prepared, RenderError> {
       let length = /* unchanged: section, else length, else Clip { loops } */;
       let kind = if let Some(grouping) = args.stems {
           stem_options(args)?;
           Kind::Stems { grouping }
       } else {
           let preset = args.preset.map(ExportPreset::from);
           export::check_length_for_preset(&length, preset).map_err(|_| usage(
               "--preset",
               "loop presets select their own bars; omit --section, --length and --loops",
           ))?;
           Kind::Mix { preset, output: mix_options(args)? }
       };
       let destination = Destination::from_out(args.out.as_deref(), &args.song).map_err(cli_error)?;
       export::prepare(
           Request { song: args.song.clone(), length, kind, jobs: args.jobs, plan_timeout: Some(args.plan_timeout) },
           destination,
       )
       .map_err(cli_error)
   }
   ```

5. **Add `cli_error`:**

   ```rust
   /// The CLI's wording of an export error: the pipeline's, except a role mismatch keeps the
   /// text the CLI printed before the module.
   pub fn cli_error(e: export::Error) -> RenderError {
       match e {
           export::Error::RolesMismatch => RenderError::Render("unexpected intro file".into()),
           other => other.into(),
       }
   }
   ```

6. **Add `ProgressLines::event(&self, event: Event<'_>, preset: bool)`:**
   - `Pipeline(p)` → `self.report(p)`;
   - `Publishing` → nothing;
   - `Written { file, new_warnings }` → `self.report(Progress::Written { path:
     file.absolute.clone() })`, then `self.warnings(new_warnings)` if `preset`, else
     `self.warnings(&file.summary.warnings)`.

   Make `partial_write` `pub(crate)`.
7. **Add `failure`:**

   ```rust
   /// Prints the partial-export line for a mix that wrote at least one file, and returns the error.
   pub fn failure(lines: &ProgressLines<'_>, e: RunError) -> RenderError {
       match e {
           RunError::Failed(e) => cli_error(e),
           RunError::PartialWrite(p) => {
               if let (Some(failed), Some(last)) = (&p.failed, p.written.last()) {
                   lines.partial_write(&last.absolute, failed);
               }
               cli_error(p.source)
           }
       }
   }
   ```

8. **Add `summary(finished, json) -> String`:**
   - **`Mix { preset: None, files }`:** for the single file, `json_line(&f.summary, &f.absolute)`
     plus `"\n"` if `json`, else `human_summary(&f.summary, &f.absolute)`.
   - **`Mix { preset: Some(p), files }`:** today's `ExportPlan::write` output tail. Build the
     `WrittenExport { role, path: f.absolute.clone(), summary: &f.summary, loop_points:
     f.loop_points.as_ref().map(LoopReport…) }` list; with `json`, print
     `{"preset": p, "files": …}`; otherwise print the human blocks with the loop line. Copy the
     text exactly.
   - **`Stems { grouping, export }`:** `stems_summary(&export, grouping, json)`.

   The CLI prints the stems warnings in `run_render`, not here.

### `crates/strudeland-cli/src/run.rs`

1. **Change the `use crate::render::{…}` line (:27)** to `use crate::render::{self,
   ProgressLines};` and add `use strudeland_render::export::{self, Finished, ReplacePolicy};`.
2. **`run` (:135):** `run_with(cli, transport, &mut export::RealPipeline, env)`.
3. **`run_with` and `execute`:** the parameter becomes `pipeline: &mut dyn export::Pipeline`, and
   the doc comment says "with the export pipeline injected".
4. **Rewrite `run_render`:**

   ```rust
   let code = read_utf8_file(&args.song, &args.song.display().to_string())?;
   let prepared = render::prepare(args).map_err(Failure::Render)?;
   let instruments = match Project::find(&args.song) {
       Some((project, _)) => project.instrument_snapshot().map_err(Failure::Project)?,
       None => Default::default(),
   };
   let preset = prepared.preset().is_some();
   let lines = ProgressLines::new(&mut *env.stderr);
   let finished = prepared
       .run(pipeline, &code, ReplacePolicy::Always, None, instruments, &|e| lines.event(e, preset))
       .map_err(|e| Failure::Render(render::failure(&lines, e)))?;
   if let Finished::Stems { export, .. } = &finished {
       lines.warnings(&export.summary.warnings);
   }
   let summary = render::summary(&finished, json);
   drop(lines);
   // write summary to stdout and flush as today
   ```

   The order matches today's:
   1. read the song;
   2. flags and destination;
   3. instruments;
   4. render;
   5. `wrote`, warnings and the partial line on stderr;
   6. `error:` from `run_with`;
   7. stdout last.

   Keep the borrow of `env.stderr` scoped as today, so `env.stdout` is free afterwards.

### Tests in `render.rs`

Replace, don't layer.

- **Delete `struct Fake` and `impl RenderBackend for Fake`.** Add local helpers:
  - `fn ok() -> FakePipeline`: `render: Some(Ok(RenderOutput { bytes: vec![1, 2, 3], summary:
    summary(Format::Wav, false) }))`;
  - `fn with(r)`;
  - `fn with_export(files)`.

  Change the `run(args, fake: &mut FakePipeline)` helper to call `run_with(&cli, &mut
  NoTransport, fake, &mut env)`.
- **Rename the fields:**
  - `fake.result` → `render`;
  - `fake.write_error` → `publish_error`;
  - `fake.writes_before_error` → `publishes_before_error`;
  - `fake.written` → `published`;
  - `seen`, `preset`, `events` and `stems` keep their names.

  Every test that reads `written` or injects `write_error` follows the rename, with the same
  expected values:
  - `split_write_failure_reports_both_destinations` (:802);
  - `preset_outputs_use_distinct_project_paths` (:1387, :1399);
  - `split_validates_the_intro_path_before_rendering` (:1427);
  - `a_failed_render_leaves_no_renders_folder` (:1444);
  - `fail` (:1479);
  - `render_encode_and_write_failures_exit_1` (:1545);
  - `a_project_song_defaults_to_renders` (:1345, :1362);
  - `only_one_shot_accepts_length_flags` (:828);
  - `success_passes_the_defaults_and_prints_the_summary` (:892);
  - and the rest.
- **Rewrite `stems_use_float_wav_and_resolve_the_project_range_directory`** to run the command
  through `run` with `FakePipeline { stems: Some(Ok(StemExport { … })), ..ok() }`. Assert:

  - `stem_targets == [root/renders/main-body-stems]`;

  `plan()` no longer exists.
- **Keep every byte-exact stderr and stdout assertion as is.** In particular:
  - `planned …\nrendered 1/2\nrendered 2/2\nencoded\nwrote …\nwarning: w one\n`;
  - the partial line;
  - the single `warning: w one` for the intro-loop pair;
  - the JSON shapes.

  If one fails, the adapter is wrong, not the test.
- **`e2e.rs` is unchanged.** It is the real-pipeline byte guard.
