# Loop export contract

Love in the Tower is the first consumer. The split preset exports all intro bars once and an isolated, tail-folded loop body that starts at frame zero. The intro stops at the musical boundary. Its effects do not feed the body, so intro sounds never recur in the loop. The handoff depends on how the song is authored. Any composed ending is excluded from both files. The tagged preset instead preserves the contiguous intro-to-loop performance in a single file and marks the one-pass loop region through EOF. The folded preset uses the same isolated body as the split preset. A one-shot preserves the existing clip, section or length semantics and appends the scheduled sound's decay.

Use the preset names in the proposal. Use automatic post-roll with no extra CLI duration flag in this release. Derive a bounded estimate from scheduled releases and effects using the lookback model as a starting point, accounting for effective duration, full IR length, and a first echo with zero delay feedback. The decay budget is an estimate, with output limits applied before allocating. A silent schedule needs zero post-roll. Keep musical and physical endpoints separate.

The host adds an optional camelCase `preset` request field with kebab-case values and an optional `export` response with `loopStartBar` (optional for one-shot) and `tailFrames`. An isolated body clamps all lookback queries to its own start. The split preset plans intro and loop as separate ranges and joins their rendered frames at the musical boundary. Only the last chunk may extend beyond its declared musical content. Default planning stays byte-equivalent. On the Rust side `render_export` takes existing render options plus a preset and returns a list of files with roles, finished render outputs and optional decoded loop points. The regular render API and CLI output are retained.

The shared finishing pass applies one gain to the split assets. A repeat-safe gain is static and considers peaks across the wrap. Use the existing configured target and ceiling. Decode lossy outputs and adjust as a group if any file goes over the ceiling. Keep loudness off as an exact PCM bypass. Use WAV's native loop chunk and text tags for compressed formats. The loop range in the public export result uses decoded frames and reports seconds for Godot's offset. The split loop and folded loop include whole-file markers as a convenience.

Encode every output before writing. Resolve paths using the project write rules. Publish each file atomically and report partial write results if needed. Default preset filenames identify their modes. For split output the projected filenames end in `-intro` and `-loop`. An existing legacy render keeps its filename and output shape.

The core fixture has distinct intro, loop and ending material and demonstrates the sequence intro once, loop at least twice. Hot wet fixtures verify modular folding, no intro leakage, and peak and length behavior. WAV is the acceptance format. Lossy decode checks include the MP3 gap warning and Opus frame-rate conversion.
