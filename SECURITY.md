# Security policy

Security reports are welcome for the current source preview on `main`.

Use the repository's [private GitHub vulnerability form](https://github.com/rudoi/strudeland/security/advisories/new).
You can also find **Report a vulnerability** on the repository's **Security → Advisories** page.
Use this channel for suspected vulnerabilities and keep sensitive details out of public issues
and pull requests. See [GitHub's reporting instructions](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately).

Include the affected revision, your macOS version, the conditions that trigger the issue, and
its impact. Share a minimal example with synthetic data where possible. Keep any follow-up in
the private report so maintainers can coordinate a fix and disclosure with you.

For ordinary bugs, see [Contributing](CONTRIBUTING.md#report-a-bug). For the expected behavior
when opening and evaluating songs, see [Projects](README.md#projects).
