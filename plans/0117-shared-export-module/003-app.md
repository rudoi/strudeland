# 003: the app on the export module

## Goal

The desktop export (`src-tauri/src/export_audio.rs`) resolves, previews, renders and publishes
through `strudeland_render::export`. The following stay byte-identical:

- the IPC types and serde shapes (`ExportRequest`, `PreviewFile`, `ExportPreview`, `FinishedFile`,
  `ExportResult`, `ExportError`, `ExportProgress`);
- every error message;
- the progress sequence;
- the paths;
- the no-clobber behaviour.

The parity test `names_and_roles_match_cli_for_every_format_and_preset` is deleted.

## Prerequisites

- **Stage 002 is committed.**
- **Read `export_audio.rs`,** and the proposal's Entry points (app), Destination resolution,
  Publish rule and Wording (app column).

## Implementation

1. **Imports (:10-18).** Keep `Project` from `strudeland_project`. From `strudeland_render`, keep
   `EncoderOptions`, `ExportPreset`, `ExportRole`, `Format`, `LengthRequest`, `Loudness`,
   `MAX_BARS`, `OutputOptions`, `Progress` and `StemGrouping`, and add `use
   strudeland_render::export;`. Remove:
   - `atomic_create_bytes`, `atomic_write_bytes`, `render_exists`, `render_filename`;
   - `export_suffix`, `render_suffix`;
   - `BitDepth`, `ExportFile`, `RenderOptions`;
   - `StemTarget`, `render`, `render_export`, `render_stems`;
   - the three stem resolvers.
2. **`ExportState::check_folder`** keeps its "choose the output folder again" check, then calls
   `export::check_chosen_folder(folder).map_err(export_error)`. Delete the free `check_directory`.
3. **Delete `Targets` and `ExportRequest::{targets, options, render_mix, write}`.** Add these to
   `ExportRequest`:

   ```rust
   /// The checks the dialog shows, in the app's order, then the module's resolution and
   /// preview. Creates nothing.
   fn prepare(&self, project: &Project, state: &ExportState)
       -> Result<(export::Prepared, export::Preview), ExportError> {
       export::check_length_for_preset(&self.length, self.preset)
           .map_err(|_| problem("loop exports use the marked loop section"))?;
       match &self.length {
           LengthRequest::Clip { loops: None } => (),
           LengthRequest::Section { name } if !name.is_empty() => (),
           LengthRequest::Length { bars } if (1..=MAX_BARS).contains(&u64::from(*bars)) => (),
           _ => return Err(problem("choose a valid clip, section, or length in bars")),
       }
       let song = project.resolve(&self.song_path).map_err(problem)?;
       if let Some(folder) = &self.folder {
           state.check_folder(folder)?;
       }
       let kind = match self.stems {
           Some(grouping) => {
               if self.preset.is_some() || self.format != Format::Wav {
                   return Err(problem("stem sets require a standard range and WAV format"));
               }
               export::Kind::Stems { grouping }
           }
           None => export::Kind::Mix {
               preset: self.preset,
               output: OutputOptions {
                   loudness: Loudness::default(),
                   encoder: EncoderOptions::default_for(self.format),
               },
           },
       };
       let destination = match &self.folder {
           Some(folder) => export::Destination::ChosenFolder(folder.clone()),
           None => export::Destination::project(project.clone()),
       };
       export::prepare_previewed(
           export::Request { song, length: self.length.clone(), kind, jobs: None,
               plan_timeout: Some(Duration::from_secs(120)) },
           destination,
       )
       .map_err(export_error)
   }
   ```

4. **Add `impl From<export::Preview> for ExportPreview`.** `Mix(files)` maps each file to
   `PreviewFile { role, path, exists }`; `Stems { directory }` maps to `Stems { directory }`.
5. **Add the wording:**
   - `fn export_message(e: &export::Error) -> String`: the proposal's Wording table, app column,
     exactly. For example `FolderChanged { path }` → `format!("the selected output folder
     changed: {}", path.display())`, and `Project { source, .. }` → `source.to_string()`.
   - `fn export_error(e: export::Error) -> ExportError`: `ExportError { message:
     export_message(&e), written: Vec::new() }`.
6. **`checked_targets` becomes `checked`,** returning `(Arc<Project>, export::Prepared,
   export::Preview)`:
   1. `current_for`;
   2. `request.prepare(&project, state)?`;
   3. if `ExportPreview::from(fresh.clone()) != *preview`, return "the output files changed;
      review the new preview before exporting".
7. **Rewrite `run`:**

   ```rust
   let (project, prepared, fresh) = checked(projects, state, request, preview)?;
   let instruments = project.instrument_snapshot().map_err(problem)?;
   let finished = prepared
       .run(
           &mut export::RealPipeline,
           source,
           export::ReplacePolicy::CreateNew { approved: replacement_approved },
           Some(&fresh),
           instruments,
           &|event| match event {
               export::Event::Pipeline(p) => progress(p.into()),
               export::Event::Publishing => progress(ExportProgress::Writing),
               export::Event::Written { file, .. } => {
                   progress(ExportProgress::Written { path: file.path.clone() })
               }
           },
       )
       .map_err(|e| match e {
           export::RunError::Failed(e) => export_error(e),
           export::RunError::PartialWrite(p) => ExportError {
               message: export_message(&p.source),
               written: p.written.into_iter().map(|w| w.path).collect(),
           },
       })?;
   Ok(match finished {
       export::Finished::Mix { files, warnings, .. } => ExportResult::Mix {
           files: files.into_iter().map(|f| FinishedFile {
               role: f.role,
               path: f.path,
               godot_loop_offset: f.loop_points.map(|p| p.godot_loop_offset()),
           }).collect(),
           warnings,
       },
       export::Finished::Stems { export, .. } => ExportResult::Stems {
           directory: export.directory,
           paths: export.files,
           warnings: export.summary.warnings,
       },
   })
   ```

   The order is unchanged:
   1. project and checks;
   2. preview comparison;
   3. instrument snapshot;
   4. approval (inside `run`, before rendering);
   5. render;
   6. `Writing`, the role check having run before it;
   7. per file: folder re-check, `exists` re-check, publish, `Written`.

   Stems behave as today: no approval, and no `Writing`.
8. **`export_audio_preview`:** `request.prepare(&project, &state).map(|(_, p)| p.into())`.
   **`export_audio_start`** calls `checked(...)` where it called `checked_targets(...)`, and builds
   `existing` from the client `preview` exactly as today.

## Tests

Replace, don't layer.

- **Delete `names_and_roles_match_cli_for_every_format_and_preset`** (:574-634) and its
  `resolve_export_output`/`resolve_output` import (:507). Stage 001's
  `destinations_resolve_every_role_without_creating_anything` covers it, including "a picked
  folder is independent of project/renders".
- **The fixture:** `Fixture::preview()` becomes `match ExportPreview::from(self.request.prepare(&self.project,
  &self.state).unwrap().1) { ExportPreview::Mix(files) => files, _ => panic!(…) }`. Each
  `f.request.targets(&f.project, &f.state)` becomes `f.request.prepare(&f.project, &f.state)`,
  and `.preview()` on it becomes `ExportPreview::from(….1)`.
- **These tests stay with their assertions unchanged:**
  - `folder_song_and_project_identity_are_checked`;
  - `reserve_one_job_and_release_on_drop`;
  - `a_changed_preview_is_refused_before_planning`;
  - `matching_preview_cannot_authorize_overwriting_a_file`;
  - `stem_preview_rejects_incompatible_settings_and_occupied_destinations`;
  - `stem_export_lists_written_paths_and_reports_collisions_after_publication`;
  - `split_wavs_include_the_first_pass_and_encoded_loop_markers`;
  - `a_collision_during_publish_preserves_the_new_file_and_reports_partial_output`;
  - the `app_quit` tests.
- **Add `export_messages_keep_their_wording`:** one row per `export::Error` variant against the
  exact app text in the proposal's Wording table. Build `Project` with
  `ProjectError::PathOutsideProject("renders/x.wav".into())` and assert its `to_string()` is the
  message. Add a `PartialWrite` row that maps `written` to the `path` fields, not `absolute`.
- **Add `preview_order_is_the_apps`** (unix, project destination, intro-loop):
  `renders/main-intro.wav` is a directory and `renders/main-loop.wav` is a symlink. The preview
  error is the intro's "not a regular output file" text (`render_exists`), not the loop's
  `PathOutsideProject`. This pins the interleaved order.
